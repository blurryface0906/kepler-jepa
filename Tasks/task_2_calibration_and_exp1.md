### Б.2. Спецификация модуля `src/models.py`
Все модели работают в `torch.float32` (при необходимости с поддержкой `torch.float64` для спектральных тестов без шума округления `float32`), принимают на вход батч контекстных окон `x_c` формы `(B, L, C)` (где $L=16$, $C \in \{2, 4\}$) и выдают латентный вектор $z_t \in \mathbb{R}^{B \times d}$ ($d = 64$).

1. **`SequenceEncoder(nn.Module)`**:
   - Поддерживает 3 варианта архитектуры (`arch_type: str` в `{"linear", "mlp", "transformer"}`):
     - `"linear"`: выравнивание окна в вектор `(B, L * C)` и один линейный слой `nn.Linear(L * C, d, bias=True)` с ортогональной инициализацией (`nn.init.orthogonal_`).
     - `"mlp"`: 3-слойный перцептрон `Linear(L * C, 128) -> GELU -> Linear(128, 128) -> GELU -> Linear(128, d)` с ортогональной инициализацией весов и малым ненулевым смещением (`bias`). Без `LayerNorm`/`BatchNorm` на последнем слое, чтобы не нормировать радиус орбиты!
     - `"transformer"`: линейная проекция каждого временного шага `Linear(C, d)` + синусоидальное позиционное кодирование длины $L$ + 2 слоя `nn.TransformerEncoderLayer(d_model=d, nhead=4, dim_feedforward=128, batch_first=True, norm_first=True)` + усреднение (mean pooling) вдоль оси времени $L$.

2. **`HorizonPredictor(nn.Module)` (Условный предиктор для 1D I-JEPA)**:
   - Принимает текущее латентное состояние `z_t` формы `(B, d)` и индекс/вектор шага горизонта `k` (целое число $k \in \{1, \dots, H\}$ или тензор шагов):
   - Содержит обучаемую или синусоидальную таблицу позиционных эмбеддингов шага горизонта `pos_emb: (H_max + 1, d)`.
   - Вычисляет $\hat{z}_{t+k} = P_\phi(z_t, m_k)$ через остаточный (residual) MLP:
     $$h = z_t + m_k, \quad \hat{z}_{t+k} = z_t + \text{MLP}(h),$$
     где `MLP` — `Linear(d, 128) -> GELU -> Linear(128, d)`. Остаточная связь $z_t + \dots$ критически важна для устойчивости авторегрессионного роллаута!

3. **Четыре класса моделей мира:**
   - **`M0_RandomJEPA(nn.Module)`**:
     - Обертка над `SequenceEncoder` (`arch_type="linear"` или `"mlp"`) и `HorizonPredictor`, веса которых инициализируются ортогонально при создании и замораживаются (`requires_grad_(False)`).
   - **`M1_IJEPA1D(nn.Module)` (Классическая 1D I-JEPA по `arXiv:2301.08243`)**:
     - Содержит `context_encoder` ($E_\theta$), `target_encoder` ($\bar{E}_{\bar{\theta}}$, создается как `copy.deepcopy(context_encoder)` с отключенными градиентами) и `predictor` ($P_\phi$).
     - Метод `update_target_ema(momentum: float = 0.996)`: обновляет параметры $\bar{\theta} \leftarrow \tau \bar{\theta} + (1 - \tau)\theta$.
     - Метод `encode_sequence(traj_windows)`: прогоняет последовательность окон `(T_eval, L, C)` через `context_encoder` (режим `T1`).
     - Метод `rollout_autoregressive(z0, steps)`: выполняет замкнутый роллаут $\hat{z}_k = P_\phi(\hat{z}_{k-1}, m_1)$ на `steps` шагов вперед (режим `T3`).
     - Метод `rollout_direct(z0, steps)`: выполняет прямое условное предсказание $\hat{z}_k = P_\phi(z_0, m_k)$ для $k = 1, \dots, \text{steps}$ (режим `T4`).
   - **`M2_JEPA_OPF(nn.Module)` (Факторизованная архитектура JEPA-Anything по `arXiv:2609.20800`)**:
     - Разбивает латентное пространство $d = 64$ на $K = 4$ подпространства (фактора) размерности $d_f = 16$: $z_t = [z_t^{(1)}, z_t^{(2)}, z_t^{(3)}, z_t^{(4)}]$.
     - Содержит $K = 4$ независимых предиктора $P_{\phi, k}: \mathbb{R}^{16} \to \mathbb{R}^{16}$ (каждый со своим позиционным эмбеддингом шага горизонта).
     - Метод `get_active_factor(Z_seq)` возвращает фактор $k^* \in \{0, 1, 2, 3\}$ с наибольшей временной дисперсией $\text{Tr}(\text{Cov}(Z^{(k)}))$.
   - **`M3_IJEPA_SIGReg(nn.Module)`**:
     - Наследует `M1_IJEPA1D`, но при обучении добавляет изотропную регуляризацию `SIGReg` ко всему вектору $z_t$.

### Б.3. Спецификация модуля `src/losses.py`
1. **`ijepa_prediction_loss(z_pred, z_target) -> torch.Tensor`**:
   - MSE между предсказанными состояниями $\hat{z}_{t+k}$ и `z_target.detach()`.
2. **`opf_orthogonality_loss(z, K=4, eps=1e-6) -> torch.Tensor`**:
   - Принимает батч латентных состояний `z` формы `(N_samples, d)`, разбивает на $K$ факторов по $d_f = d / K$.
   - Центрирует и нормирует каждый фактор по стандартному отклонению, после чего вычисляет сумму квадратов норм Фробениуса взаимных матриц корреляции/ковариации между разными факторами $j \neq k$:
     $$\mathcal{L}_{\text{ortho}} = \frac{1}{K(K-1)} \sum_{j \neq k} \|C_{jk}\|_F^2.$$
3. **`sigreg_isotropic_loss(z) -> torch.Tensor`**:
   - Реализует формулу $\mathcal{L}_{\text{SIGReg}}(z) = \|\mu(z)\|_2^2 + \|\Sigma(z) - I\|_F^2$ по батчу.
