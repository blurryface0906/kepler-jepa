### Б.2. Математическая и инженерная спецификация обучения (`src/train.py`)

Чтобы обученный предиктор $P_\phi$ в моделях `M1_IJEPA1D` и `M2_JEPA_OPF` генерировал устойчивые консервативные траектории в замкнутом цикле (`T3`) и в прямом многошаговом предсказании (`T4`), реализовать следующий протокол обучения на GPU:

1. **Шаг предсказания и горизонт:**
   - Контекстное окно $x_t^c$ имеет длину $L = 16$ при шаге симулятора $\Delta t = 0.01$.
   - Один макро-шаг предиктора ($k = 1$) сдвигает окно на $\delta = 2$ (или $\delta = 4$) базовых шага симулятора ($\Delta t_{\text{pred}} = \delta \cdot \Delta t$).
   - Максимальный горизонт прямого предсказания при обучении: $H_{\text{train}} = 64$ макро-шага.
   - При оценке (`eval`) длина генерируемой латентной траектории составляет $N_{\text{eval}} = 256$ макро-шагов (что покрывает несколько полных периодов обращения и устраняет краевые эффекты короткой дуги).

2. **Функционал потерь при обучении:**
   В каждом батче (`batch_size = 256`) сэмплируются стартовые окна $(o_b, t_b)$ из `Dataset-Circ (train)` ($N=200$ орбит):
   - **Direct Multi-Horizon Loss ($\mathcal{L}_{\text{dir}}$):** предсказание $\hat{z}_{t + k\delta}^{\text{dir}} = P_\phi(z_t, m_k)$ по сетке горизонтов $k \in \{1, \dots, H_{\text{train}}\}$ против целевого EMA-энкодера $z_{t + k\delta}^* = \text{sg}(\bar{E}_{\bar{\theta}}(x_{t + k\delta}^y))$:
     $$\mathcal{L}_{\text{dir}} = \frac{1}{H_{\text{train}}} \sum_{k=1}^{H_{\text{train}}} \left\| \hat{z}_{t + k\delta}^{\text{dir}} - z_{t + k\delta}^* \right\|_2^2.$$
   - **Autoregressive Rollout + Velocity Loss ($\mathcal{L}_{\text{ar}}$):** замкнутый разворот предиктора на $K_{\text{ar}} = 16$ шагов с токеном $m_1$ ($\hat{z}^{(s)} = P_\phi(\hat{z}^{(s-1)}, m_1)$, $\hat{z}^{(0)} = z_t$) с выравниванием как самих состояний, так и первых разностей (скоростей) $\Delta \hat{z}^{(s)} = \hat{z}^{(s)} - \hat{z}^{(s-1)}$ против $\Delta z^{*(s)} = z_{t+s\delta}^* - z_{t+(s-1)\delta}^*$:
     $$\mathcal{L}_{\text{ar}} = \frac{1}{K_{\text{ar}}} \sum_{s=1}^{K_{\text{ar}}} \left( \left\| \hat{z}^{(s)} - z_{t + s\delta}^* \right\|_2^2 + \lambda_{\text{vel}} \left\| \Delta \hat{z}^{(s)} - \Delta z^{*(s)} \right\|_2^2 \right), \quad \lambda_{\text{vel}} = 1.0.$$
   - **Защита от коллапса в `M1` и `M2` ($\mathcal{L}_{\text{var}}$):**
     Чтобы EMA-таргет не сжимал амплитуду представлений к нулю, добавляется мягкий барьер на среднеквадратичное отклонение координат $z_t$ и приращений $\Delta z_t$ **вдоль батча (по ансамблю всех орбит)**:
     $$\mathcal{L}_{\text{var}}(z_t) = \frac{1}{d}\sum_{j=1}^d \max\left(0, \, \gamma_0 - \sqrt{\text{Var}_B(z_{t, j}) + 10^{-6}}\right) + \frac{1}{d}\sum_{j=1}^d \max\left(0, \, \gamma_1 - \sqrt{\text{Var}_B(\Delta z_{t, j}) + 10^{-6}}\right),$$
     где $\gamma_0 = 0.5, \, \gamma_1 = 0.05$. Барьер считается только по всему батчу целиком, поэтому он **не уравнивает** радиусы разных орбит между собой.

3. **Различия между обучаемыми моделями `M1`, `M2`, `M3`:**
   - **`M1_IJEPA1D` (Классическая 1D I-JEPA):**
     $$\mathcal{L}_{M1} = \mathcal{L}_{\text{dir}} + \mathcal{L}_{\text{ar}} + 0.1 \mathcal{L}_{\text{var}}(z_t).$$
   - **`M2_JEPA_OPF` (JEPA-Anything с $K=4$ ортогональными факторами):**
     $$\mathcal{L}_{M2} = \mathcal{L}_{M1} + \lambda_{\text{ortho}} \mathcal{L}_{\text{ortho}}(z_t) + \lambda_{\text{sp}} \mathcal{L}_{\text{sparsity}}(z_t),$$
     где $\mathcal{L}_{\text{ortho}}$ штрафует ковариацию между разными факторами $j \neq k$ ($\lambda_{\text{ortho}} = 0.2$), а опциональный член $\mathcal{L}_{\text{sparsity}}$ поощряет концентрацию динамики в ведущем орбитальном факторе.
   - **`M3_IJEPA_SIGReg` (Абляция для проверки Гипотезы H4 — принудительная изотропная нормализация):**
     Моделирует агрессивное приведение каждого латентного представления к единичной изотропной сфере (как при применении `LayerNorm` / по-орбитального выбеливания $\Sigma(z^{(i)}) \to I$ + глобального `sigreg_isotropic_loss(z)` с весом $\beta = 1.0$). Это позволяет строго проверить Гипотезу H4: сохраняется ли при таком ограничении частота вращения $\hat{\omega}_i$ (фаза) при полной потере информации о радиусе орбиты $a_i$ (масштабе).

4. **Режим оптимизации:**
   - Архитектура энкодера: `arch_type = "mlp"` (и дополнительно при наличии ресурсов GPU можно сравнить с `"transformer"`).
   - Оптимизатор: `AdamW(lr=1e-3, weight_decay=1e-4)` с косинусным затуханием до `1e-5`.
   - Число шагов: `steps = 2000` на GPU (`batch_size = 256`), клиппинг градиента `max_norm = 1.0`, EMA-моментум целевого энкодера линейно или косинусно растет от `0.99` до `0.999`.

### Б.3. Диагностика сохранения масштаба полуоси $a$ и энергии $E$ (Проверка Гипотезы H4)

Реализовать функцию `evaluate_scale_preservation(Z_all_orbits, semi_major_axes, mu=1.0) -> dict`:
- Вход: `Z_all_orbits` формы `(N_orbits, N_eval, d)` (в режиме `T1` и `T3`) и `semi_major_axes` формы `(N_orbits,)`.
- Для каждой орбиты $i$ вычисляются:
  1. Логарифм среднеквадратичного радиуса латентной траектории относительно её центра:
     $$s_i = \log \sqrt{\frac{1}{N_{\text{eval}}} \sum_{t=1}^{N_{\text{eval}}} \left\| Z_{i, t} - \bar{Z}_i \right\|_2^2 + 10^{-12}}.$$
  2. Логарифм среднеквадратичной нормы самого вектора состояния:
     $$r_i = \log \sqrt{\frac{1}{N_{\text{eval}}} \sum_{t=1}^{N_{\text{eval}}} \left\| Z_{i, t} \right\|_2^2 + 10^{-12}}.$$
- Вычисляются и возвращаются метрики:
  - `scale_r2_cycle_radius`: $R^2$ линейной регрессии $\log a_i = \alpha_1 s_i + \alpha_0$;
  - `scale_r2_state_norm`: $R^2$ линейной регрессии $\log a_i = \gamma_1 r_i + \gamma_0$;
  - `energy_r2`: $R^2$ линейной регрессии логарифма модуля механической энергии $\log |E_i| = \log\left(\frac{\mu}{2a_i}\right)$ по $(s_i, r_i)$.
