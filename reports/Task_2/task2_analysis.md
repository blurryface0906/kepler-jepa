## Реализация и unit-тесты

- `integrate_verlet(..., substeps=1)` поддерживает подшаги при сохранении
  прежней сетки выходных отсчетов. Старые вызовы дают прежний результат.
- DMD и Phase Unwrap поддерживают `use_differences=True`; после `np.diff`
  среднее не вычитается повторно.
- Реализованы три `SequenceEncoder`, остаточный `HorizonPredictor`,
  M0–M3, EMA, независимые факторные предикторы, T1/T3/T4 API.
- Реализованы MSE со stop-gradient, стандартизованная межфакторная
  корреляция и заданный моментный изотропный штраф. Последний соответствует
  формуле ТЗ, а не полному алгоритму SIGReg в LeJEPA.
- `float32` остается режимом моделей по умолчанию. В спектральном
  эксперименте ортогональные веса создаются сразу в `float64`.
- 52 теста состоят из прежних 26, 16 тестов моделей/лоссов, 7 проверок
  подшагов/разностей и 3 проверок честной обработки критериев эксперимента.

## Часть A: все 15 критериев PASS

Пять seed: `42,43,44,45,46`. В контрфактическом длинном тесте использованы
все 50 орбит, 16384 отсчета и пять подшагов; подмножество не отбиралось.

| Проверка | Фактический результат |
| --- | --- |
| Максимальный аналитический дрейф энергии | около `6.38e-15`, ниже `1e-13` |
| Верле, один подшаг | максимум `2.47284e-3`, ниже `3e-3` |
| Верле, пять подшагов | максимум `9.92659e-5`, ниже `1.5e-4` |
| Знакопеременность энергии | у 100% орбит с наблюдением не менее периода |
| Короткая дуга S1 | один бин, регрессионный R² не определен — ожидаемое вырождение |
| Центрированная короткая дуга, разностные S3 | максимальная ошибка наклона около `2.86e-13`, остаток не более `3.70e-25` |
| Длинное окно S1 | `1-R²=0.0114226144`, в заданном диапазоне |
| Длинное окно S2 | `R²≈0.999975994`, выше `0.9999` |
| Короткие эллипсы | апсидные неравенства выполнены на всех орбитах; наклоны в заданном допуске |
| Длинный контрфактический тест | минимальный log-identity R² S2/S3b около `0.999953`, выше `0.999` |

Сохраняется существенное различие между физическим и выборочным началом
координат. Длинные стандартные S3 проверяются на исходных физических
координатах; центрированные стандартные оценки выведены отдельно.
У центрированного стандартного Phase Unwrap `1-R²≈1.344e-6`, а у
разностного после того же центрирования — около `3.35e-31`.
Поэтому успешная проверка стандартного S3 на физическом начале не
выдается за успешную проверку на произвольном центрированном ряде.

## Часть B: что показал Эксперимент №1

Использована существующая сетка `Dataset-Circ(test_id)`: 30 радиусов
`a∈[0.5029010787,1.9513952697]`. Три случайных энкодера, два горизонта
`256/4096`, шесть оценщиков, пять seed. Получено 180 регрессий по 30
орбитам, всего 5400 оценок частоты. Никакие орбиты или seed не удалялись.

### Линейный энкодер: строгие критерии H1 выполнены

Оба разностных метода на обеих длинах окна проходят
`abs(slope+1.5)<1e-10` и `1-R²<1e-20` на всех пяти seed.
Для длинного окна средние остатки:

| Метод | Среднее `SSE/SST` |
| --- | ---: |
| S1 | `1.14226144e-2` |
| S2 | `2.40056176e-5` |
| S3a_diff | `6.51619526e-26` |
| S3b_diff | `2.80629774e-31` |

Прямоугольная проекция вообще не обязана сохранять фазу круга. Здесь
равенство входной размерности `L*C=64` и латентной `d=64` вместе с
ортогональными весами сохраняет геометрию гармонической плоскости;
разности устраняют константное смещение и центрирование.

### Нелинейные энкодеры: частичное подтверждение H1

Transformer проходит заданные пороги длинного окна на всех пяти seed.
У MLP средние метрики стандартной фазы проходят, но seed 42 выходит за
порог остатка. Поскольку в отчете пороги проверяются по каждому seed,
этот контроль помечен `FAIL`:

| MLP, seed 42, T=4096 | `SSE/SST` | Порог |
| --- | ---: | ---: |
| S3b_std | `1.0960278055e-5` | `<1e-5` |
| S3b_diff | `4.6185103306e-5` | `<1e-5` |

Остальные четыре seed проходят фазовые критерии. Среднее `S3b_std`
по пяти seed дает `R²≈0.999993393` и ошибку наклона около `0.0006013`.
Это различие между хорошим средним результатом и гарантированным
прохождением каждого запуска сохранено явно. Оно не является основанием
подбирать другой seed или менять случайные веса ради приемки.

Нелинейное отображение сохраняет периодичность входа, но может менять
гармонический состав и геометрию ведущей PCA-плоскости. Разностная фаза
не исправляет произвольную нелинейную деформацию. Поэтому универсальное
утверждение о любой необученной сети этим экспериментом не доказано.

### H2: численный механизм показан в контролируемом T1

При 4096 отсчетах дискретный FFT дает `R²≈0.988577386`; разностные
непрерывные оценки линейной гармонической моды снижают остаток примерно
на 23–29 порядков. Следовательно, чрезвычайно высокий R² может быть
получен вообще без обучения энкодера в этом контролируемом режиме.

Это показывает достаточный численный механизм, но не устанавливает
происхождение конкретного опубликованного числа JEPA-Anything: для
этого нужен оригинальный протокол извлечения латентов и оценивания
частоты. Здесь не исследовалась выученная динамика, поскольку предиктор
не используется в T1.
